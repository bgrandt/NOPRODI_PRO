# noprodi

An open-source project for storing nutritional data and calculating nutritional values for recipes. This project is intended for dietitians or anyone else interested in nutrition.

## Current Status

**Early development / prototype**

The current focus is on developing the underlying nutrition database and its structure. The project is not yet a finished application.

## Planned Features

### Nutrition Database

A basic database for storing:

* Foods and ingredients
* Nutritional values
* Relevant units and metadata

### Recipe Calculations

Recipes will be composed of foods from the database. The system should be able to:

* Calculate the nutritional values of a complete recipe
* Calculate values based on portion size
* Scale recipes to different numbers of portions

### User-Defined Foods

Users should be able to add their own foods and nutritional data without needing knowledge of SQL or database management.

Possible approaches include:

* Simple Jupyter notebooks
* A user-friendly web interface

The exact implementation is still to be decided.

## Future Ideas

Possible future additions may include:

* Nutritional analysis and visualisation
* Food and recipe comparisons
* Additional food metadata
* Import and export functionality

These are ideas for future development rather than currently implemented features.

## Project Goal

The goal of NOPRODI_PRO is to create a **simple, open and extensible nutrition database and calculation tool** that can be used without requiring database knowledge.
